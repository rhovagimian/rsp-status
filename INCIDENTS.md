# Posting incidents

An incident is a GitHub issue in this repository with the `status` label. Add the label of each affected component: `web-app`, `offers-and-signing`, `bank-linking`, `disbursements`, `notifications`. Every comment on the issue is shown on the status page as an update, and closing the issue resolves it.

Open a new incident from **Issues > New issue** and pick a template:

- **Incident: investigating** for anything unexpected
- **Incident: disbursements paused** when payouts are stopped on purpose

## Update: monitoring

Post as a comment:

> We have applied a fix and are monitoring. <What firms should see now.> We will post again within 1 hour or when we resolve this.

## Update: resolved

Post as a comment, then close the issue:

> This is resolved. <What happened, in one sentence, and anything firms need to do.> If you still see a problem, contact support@readysettlepay.com.
